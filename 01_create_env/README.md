# 📘 Environment Setup — Part 1 of the Series

This folder is the **first installment** in the *AI Systems Architecture* learning series. It focuses entirely on preparing a clean, reliable development environment before moving on to more advanced topics.

## 🔧 What’s Included  
- `environment.yml` — the official environment specification  
- `requirements.txt` — Python package list  
- Example notebooks and starter scripts (`Fibonacci.py`, introductory Python notebooks)

## 🐍 Python Version Requirement  
This project **must be run using Python 3.11**.  
All environment files and dependencies are aligned specifically with this version.

## 🚀 How to Use  
Follow the setup steps **exactly as provided** to ensure compatibility with the rest of the series.

### Create the Conda Environment  
```bash
conda env create -f environment.yml
conda activate ai-systems-architecture
```

### Or install via pip  
```bash
pip install -r requirements.txt
```
