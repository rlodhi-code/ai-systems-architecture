One thing worth noting: since langchain jumped from 0.2.8 → 1.3.1, there are some API changes. The most common ones you may encounter in notebooks:

from langchain.chat_models import ChatOpenAI → now from langchain_openai import ChatOpenAI
from langchain.embeddings import OpenAIEmbeddings → now from langchain_openai import OpenAIEmbeddings
from langchain.vectorstores import Chroma → now from langchain_chroma import Chroma
