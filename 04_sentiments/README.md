# 💬 Sentiment Analysis — Part of the *ai-systems-architecture* Series

This project introduces core sentiment‑analysis techniques using multiple approaches, including lexicon‑based methods, VADER, and pretrained models. It is designed as a practical, hands‑on module within the broader **ai-systems-architecture** learning path.

---

## 📁 Project Contents

- **book_reviews.csv**  
  Dataset of short book reviews used for sentiment exploration.

- **book_reviews_analysis.ipynb**  
  A guided notebook that walks through cleaning, analyzing, and interpreting sentiment in the dataset.

- **lexicon_vs_vader_vs_pretrained.ipynb**  
  A comparative notebook demonstrating how different sentiment‑analysis methods behave on the same text samples.

---

## 🎯 What You’ll Learn

### **1. Lexicon‑Based Sentiment Analysis**
- Uses predefined word lists with positive/negative scores  
- Simple, interpretable, and fast  
- Good for rule‑based or lightweight applications  

### **2. VADER (Valence Aware Dictionary and sEntiment Reasoner)**
- Designed for social‑media style text  
- Handles punctuation, capitalization, emojis, and slang  
- Produces compound sentiment scores  

### **3. Pretrained Model Approach**
- Uses modern NLP embeddings or transformer‑based models  
- Captures context and nuance  
- More accurate but computationally heavier  

---

## 🧪 Workflow Overview

Across the notebooks, the following steps are demonstrated:

- Load and inspect the dataset  
- Clean and normalize text  
- Apply lexicon‑based scoring  
- Run VADER sentiment analysis  
- Compare results with a pretrained model  
- Visualize and interpret differences  
- Discuss strengths and limitations of each method
